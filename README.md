# ankitjy.github.io

 Webpage **[ankitjy.github.io](https://ankitjy.github.io)**.

## Structure

```
.
├── index.html               # Home page
├── towards-research.html    # Research, seminars & workshops
├── misc.html                # Miscellaneous projects
├── 404.html                 # Custom "page not found"
├── css/
│   ├── themes.css           # Light & dark colour themes
│   ├── base.css             # Base typography & layout
│   ├── components.css       # Header, footer & other components
│   └── responsive.css       # Mobile / small-screen styles
├── js/
│   ├── theme-init.js        # Applies saved theme before page renders
│   ├── theme.js             # Light/dark toggle button
│   └── components.js        # Site config (nav, links) + shared header & footer
├── data/                    # Favicons and icons
├── sitemap.xml              # Sitemap for search engines
├── robots.txt               # Crawler rules
└── .nojekyll                # Serve files as-is (no Jekyll build)
```
